Cubex — Subsystem technology that integrates with system security and
makes configurations immutable at startup.

Usage:
    cubex <command> [arguments]

Image commands:
    search, s <URL>                  Search for an image
    pull, p <URL>                    Pull an image

Subsystem commands:
    create, c <image ID> <name>      Create a subsystem
    start, st <name>                 Start a subsystem
    stop, sp <name>                  Stop a subsystem
    run, rn <name>                   Run a subsystem
    list, l                          List running subsystems
    list all, list -a                     List all subsystems
    clean subsystem, clean ss        Clean subsystem data

Registry commands:
    list registry, l r               List registered images

Data management:
    clean all, clean -a              Clean all Cubex data

General options:
    help, -h, --help                 Show this help message
    version, -v, --version            Show version information

Workflow Order:
    Search image -> Pull -> Create subsystem -> Start -> Run
    You pass network config, paths bind, devices, displays, and others at
    start so, you can always change it by stoping, starting, and running again
